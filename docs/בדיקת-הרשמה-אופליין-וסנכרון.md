## פערים שהתגלו בבדיקת הקוד

1. **הגנת סיסמת הרשמה ממתינה:** `localAccount.ts` שומר סוד בהסוואה הפיכה עם מפתח קבוע. זו אינה הגנה קריפטוגרפית. יש להחליט בין אחסון מאובטח במערכת ההפעלה לבין בקשת סיסמה מחדש כשחוזר החיבור; בדפדפן אין להציג הסוואה כאבטחה.
2. **כשל כתיבה לתור נבלע:** `enqueueFullSyncJob` ב־`indexedStateCache.ts` תופס שגיאות בלי לדווח לכותר. לכן הצלחת פונקציית הרשמה אינה הוכחה שהמשימה נשמרה. יש להפיץ את הכשל ולשמור מצב ממתין עד אישור כתיבה.
3. **חיווי מטעה לאחר כישלון מלא:** `runPendingCloudSync` ב־`store.ts` מעדכן את המונה ל־0 כאשר לא עובדה בהצלחה אף משימה, אף שהמשימות שנכשלו עשויות להישאר בתור. יש לחשב את מספר המשימות שנותרו גם בכישלון.
4. **החלפת חשבון בזמן הרשמה:** ההרשמה לוכדת את החשבון בתחילת הבקשה, אך `markRegistered` קורא שוב את החשבון הפעיל בסופה. החלפת חשבון בזמן ההמתנה עלולה לסמן רשומה אחרת. נדרשת הצמדה לזהות המקורית ובדיקת מרוץ ייעודית; לא שוחזר בבדיקה דינמית בסבב זה.
